# Ember & Oak — Specialty Coffee Roasters ☕

Ember & Oak is a premium, high-end landing page for a specialty coffee roastery based in Mumbai. The project focuses on a modern, dark-themed aesthetic (Apple-inspired) with smooth, scroll-driven animations and a luxurious user experience.

![Ember & Oak Preview](hero_coffee_shot_1777193755026.png)

## ✨ Key Features

- **Apple-Inspired Design**: A sleek, minimal, and high-contrast dark theme using Inter typography and premium spacing.
- **Scroll Reveal Animations**: Dynamic content entry using the Intersection Observer API for sections, cards, and images.
- **Inner Image Animations**: Sophisticated "mask-reveal" effects where photos expand vertically as they enter the viewport.
- **Liquid Glass UI**: Custom buttons and cards with glassmorphism, blur effects, and morphing "liquid" hover states.
- **Interactive Menu**: A filterable menu section allowing users to toggle between Hot, Cold, and Specialty brews.
- **Full-Screen Gallery**: A dedicated gallery section with a custom-built Lightbox modal for zooming into high-quality atmospheric shots.
- **Grain Overlay**: A subtle, animated noise texture across the site to provide a tactile, organic feel.
- **Fully Responsive**: Meticulously crafted media queries ensure a seamless experience from large monitors to mobile devices.

## 🛠 Tech Stack

- **Frontend**:
  - Semantic HTML5
  - CSS3 (Custom Properties, Grid, Flexbox, Keyframe Animations)
  - Vanilla JavaScript (ES6+, Intersection Observer API)
- **Backend**:
  - Node.js & Express (for serving static assets and handling reservations)
- **Fonts**:
  - Inter (Google Fonts)
  - Bebas Neue (for Branding)

## 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone or Download** the repository to your local machine.
2. **Install Dependencies**:
   ```bash
   npm install
   ```
3. **Start the Server**:

   ```bash
   npm start
   ```

   The project will be available at `http://localhost:3000`.

4. **Development Mode** (with auto-restart):
   ```bash
   npm run dev
   ```
